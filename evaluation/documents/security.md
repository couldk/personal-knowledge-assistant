# Agent 安全与隐私

API Key 应保存在本地环境变量或密钥管理系统中，不能写入源代码、测试数据和日志。项目的 .env 必须被 .gitignore 忽略，.env.example 只能保留变量名和非敏感示例，不能包含真实密钥。生产环境还应遵循最小权限原则并定期轮换密钥。

Prompt Injection 可能诱导 Agent 忽略规则、泄露数据或调用高风险工具。工具层需要参数校验、权限边界和必要的人工审批，不能仅依赖模型判断。来自网页和文档的内容应被视为不可信数据，而不是更高优先级指令。

日志和 Trace 默认不应保存完整私人查询或文档正文。可以记录查询哈希、Chunk ID、相似度分数、模型名和耗时用于排障。多用户数据必须通过 tenant_id 和 user_id 隔离，并在检索过滤、缓存、记忆和数据库访问层同时执行隔离规则。
