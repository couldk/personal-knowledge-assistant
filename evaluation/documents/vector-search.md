# 向量检索基础

Embedding 模型把文本转换成固定长度的浮点向量，使语义相近但措辞不同的文本在向量空间中彼此接近。查询文本和文档片段必须使用同一个 Embedding 模型及相同维度，否则相似度没有可比性，也无法写入同一个向量索引。更换 Embedding 模型或维度后，应重新生成全部文档向量并重建索引。

余弦相似度通过比较两个向量的方向衡量语义接近程度。top-k 参数控制一次查询最多返回多少个相似片段。较大的 top-k 可以提高召回率，但也会增加后续上下文长度和噪声。

HNSW 是常见的近似最近邻索引，通过多层图结构加快大规模向量搜索。它牺牲少量精确性换取更低延迟。评测检索系统时应固定模型、维度、切块方式和问题集，再比较 Hit@1、Recall@3、MRR 与延迟。
