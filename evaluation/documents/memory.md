# Agent 记忆管理

短期记忆保存当前对话的近期消息和工作状态，通常随线程生命周期存在。长期记忆保存能够跨会话复用的信息，包括语义记忆、情景记忆和用户偏好。语义记忆用于保存经过验证的事实，情景记忆只保存具有复用价值的成功或失败任务摘要。

长期记忆不能无限期保留。每条记忆应记录来源、置信度、创建时间、最后确认时间和过期策略。模型只能提出结构化的记忆候选，应用代码负责校验和最终写入，避免把模型幻觉直接变成永久事实。

多用户系统必须通过 tenant_id 和 user_id 隔离记忆。用户 A 的查询在任何情况下都不能读取用户 B 的偏好或历史。Checkpoint 用于恢复图执行状态，不等同于经过验证、可以跨线程复用的长期用户记忆。
