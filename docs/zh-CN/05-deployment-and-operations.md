# 部署与运维

## 环境

- 本地环境：API、PostgreSQL/pgvector，以及可选的 LangSmith Trace。
- 预发布环境：使用合成文档的生产等价数据库。
- 生产环境：托管数据库、密钥管理器、TLS、备份和租户感知认证。

## 配置

必需配置包括模型提供商、模型名称、Embedding 模型及维度、数据库 URL、最大检索片段数、超时和 Trace 采样率。

Embedding 模型及维度必须与索引版本绑定。修改其中任何一项都需要新索引或迁移流程。

## 可观测性

采集以下信息：

- 请求 ID 和 Trace ID。
- 图节点耗时。
- 检索片段 ID 和分数；默认不记录完整私有文本。
- 输入/输出 Token 数和估算成本。
- 拒答、校验失败和记忆写入次数。

## 运维流程

- 备份文档元数据、记忆和 Checkpoint。
- 向量索引必须能够从源文档重建，不能把 Embedding 当作唯一副本。
- 升级模型、Prompt、Embedding、切分策略或框架前运行黄金数据集。
- 将生产中失败和低置信度的 Trace 抽样加入离线评测集。

## 发布门禁

当租户隔离失败、引用准确率下降超过 5 个百分点，或缺少依赖锁文件时，不得发布。
